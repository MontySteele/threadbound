S20-R1 — the canonical anchor re-bank (sprint doc Part 1, item 4)
==================================================================

The S20.1 canon flip changed the anchor ENVIRONMENT: TB_RITES, TB_TRACKS,
and TB_KNOTWORK are the global default, so the canonical battery command
carries NO env prefix beyond the seed window and shard pin. This board is
the successor anchor set to S18-P2000/S19 (docs/reference/s19-p2000-bank.txt,
whose environment — knotwork-on, rites-OFF, tracks-OFF — is now archaeology).
Correction on the record: the sprint doc's Part 0 said the old anchors were
"rites-on"; the S19 bank's own command line shows they were rites-off too,
so this re-bank moves TWO flags' worth of environment, not one.
